# 発音機能のルール

仕様の本体は `docs/phonetics.md`。以下は実装時に必ず守ること。

## 閾値
- **較正前の数値をハードコードしない。** VOT の境界値、なぞりの許容誤差、
  類似度スコアの閾値は、文献値または実測値に基づいて決め、根拠をコメントに残す
- 決められない場合は実装を止めてユーザーに相談する

## 測定できないときの扱い
- SNR が低い、音量が足りない、無音 → **判定せず、理由と対処を返す**
- 「たぶん合っている」を返さない。測れなかったことを正直に言う

## マイクとプライバシー
- 録音データは端末内で処理し、既定では保存しない。
- Web Speech API は**音声を外部サーバーに送る**。この機能は既定オフ・明示的オプトインとする。
- マイク権限が拒否されても、発音機能以外はすべて動くこと。
